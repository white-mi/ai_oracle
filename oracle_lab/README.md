# oracle_lab

Каркас кода для плана экспериментов (вкладка «План экспериментов» отчёта): гипотезы H1-H4, наборы D1 и D2.

## Что внутри

| Модуль | Что делает | Правило плана |
|---|---|---|
| `store.py` | Ключ вопроса из id рынка, текста вопроса и хэша правил. Кэш вызовов в JSONL, хранилище пакетов | 2, 3, 8 |
| `evidence.py` | Поиск Exa с настройками статьи, четыре шаблона запроса, фильтр сайтов рынков, объединение пакетов, признак «вышел после закрытия», проверка наличия текста в промпте | 1, 4, 7 |
| `prompts.py` | Свои промпты (вероятность YES, отказ, без поиска, второй раунд) и загрузка промптов статьи из её репозитория | 6 |
| `llm.py` | Клиенты OpenRouter, Anthropic API, Jev (typesafe_sdk 0.7.2) и бесплатный FakeClient для пробных прогонов | 8 |
| `metrics.py` | Макнемар, Уилсон, кластерный бутстреп, TOST, Холм, AURC, покрытие при заданной точности, порог для переноса на D2, Brier, ECE, гауссова копула | 9 |
| `kalshi.py` | Выгрузка закрытых рынков Kalshi для D2 | |
| `run.py` | Командная строка: импорт данных статьи, сбор пакетов, прогон условия, выгрузка D2 | |

## Что проверено

`python tests/test_offline.py` проходит без сети и ключей. С переменной `KOTA_REPO` (клон репозитория статьи) тесты дополнительно:

- импортируют D1 (1 188 различных вопросов) и 432 сохранённых пакета статьи;
- прогоняют проверку текста на всех пакетах (10 из 432 не проходят, у них у большинства источников меньше 200 знаков текста, такие пакеты стоит смотреть руками);
- делают пробный прогон конвейера на 60 вопросах с FakeClient;
- воспроизводят AURC 0,051 для сигнала статьи на 1 153 строках.

Сетевые клиенты (Exa, OpenRouter, Anthropic, Jev, Kalshi) написаны по документации и коду статьи, но с живыми сервисами не проверялись. Первый шаг после получения ключей: прогон на 5 вопросах и сверка сырых ответов.

## Быстрый старт

```bash
pip install pandas numpy scipy requests exa_py typesafe-sdk==0.7.2
git clone https://github.com/Tkota10/Senior-Thesis-Multi-LLM-Resolution repo   # репозиторий статьи
git -C repo checkout f76754b                                                      # версия, на которой делался аудит
python -m oracle_lab.run import-paper --repo repo --work work
python -m oracle_lab.run answer --data work/d1.csv --work work --variant paper_cache --condition prob \
       --model fake:x --out work/results/fake.csv --limit 50          # бесплатно
python -m oracle_lab.run answer ... --dry-count                       # только посчитать вызовы
```

Ключи берутся из переменных окружения `EXA_API_KEY`, `OPENROUTER_API_KEY`, `ANTHROPIC_API_KEY`, `TYPESAFE_API_KEY`. Используйте ключи с лимитом расходов. Подписка чата для массовых прогонов не подходит.

Шаблоны запросов в `evidence.query_templates` (кроме `paper`) и тексты промптов в `prompts.py` это черновики. Их нужно зафиксировать коммитом пререгистрации до первого платного прогона.
